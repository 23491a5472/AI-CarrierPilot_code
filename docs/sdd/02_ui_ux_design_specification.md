# UI/UX Design Specification

## Design Philosophy
The application follows the **"Apple + Headspace"** emotional premium aesthetic. It avoids cyberpunk, neon, and heavy "AI-glow" themes entirely. The goal is to feel organic, human-designed, and calming.

## Visual Characteristics
1. **Layered Depth:** Extensive use of `BackdropFilter` to create frosted glassmorphism cards that float above the background.
2. **Organic Gradients:** Soft, warm, out-of-focus background radial gradients ("blobs") provide texture.
3. **Premium Typography:** Clean, heavy headings with highly legible body text.
4. **Delightful Animation:** Micro-interactions (scaling, sliding, fading) powered by `flutter_animate`.
